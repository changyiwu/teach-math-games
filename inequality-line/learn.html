數線畫解小抄

康軒 1 下 4-1 認識一元一次不等式。把解畫在數線上只要決定兩件事：往哪邊畫（比端點大還是小）、端點空心還是實心（有沒有等號）。

一個不等號：從端點畫到盡頭

方向：數線愈右邊愈大，x > a、x ≥ a 往右畫；x < a、x ≤ a 往左畫。
端點：沒有等號（>、<）畫空心圓圈 ○，a 不是解；有等號（≥、≤）畫實心圓點 ●，a 也是解。
倒著寫：2 < x 要從 x 這邊讀回來，就是 x > 2，往右畫。

兩個不等號：只畫中間一段

兩個端點各自判斷：旁邊的不等號有等號就實心，沒有就空心。解只在兩端之間，不延伸到盡頭。

數整數解：先畫圖，再數點

實心端點要算、空心端點不算。「正整數」「負整數」都不含 0。
兩端都是整數時，a ≤ x ≤ b 有 b − a + 1 個整數；每多一端是空心就少 1 個。

習慣用語對照表

翻譯一個詞只問兩件事：比界線大還是小？剛好等於界線算不算？
習慣用語不等號剛好等於算不算端點
大於、超過、高於>不算○ 空心，往右
小於、未滿、低於、不到<不算○ 空心，往左
不小於、不低於、至少、以上（含）≥算● 實心，往右
不大於、不超過、至多、以下（含）≤算● 實心，往左

常見錯誤

常見的想法正確
x ≥ 3 畫空心有等號，3 也是解，要畫實心
−2 < x 看到「<」就往左畫從 x 讀回來是 x > −2，往右畫
「不超過 5」有個「不」字，所以是 x > 5沒有超過 → 比 5 小或剛好 5 → x ≤ 5
「未滿 12 歲」包含 12 歲未滿不含界線：x < 12，空心
−1 ≤ x < 4 兩端都往外延伸兩個不等號只畫 −1 到 4 中間一段
x ≤ 3 的正整數解是 0、1、2、30 不是正整數，答案是 1、2、3
