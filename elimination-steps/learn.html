消去法小抄

康軒 1 下 1-2。兩個未知數太多了：先消去一個未知數，變成一元一次方程式解出來，再代回求另一個。

解聯立方程式的流程

能讓兩條方程式同時成立的 x、y 值（共同解），就是聯立方程式的解。 解的方法：代入消去法或加減消去法消去一個未知數 → 解一元一次方程式 → 把解代回任一條式子求另一個未知數 → 代回兩條原式驗算。

代入消去法：有現成的「x = …」就直接代

已經是 y = … 的樣子
y = 2 − 3x①
4x + 2y = 6② 把①代入②：② 的 y 換成 (2 − 3x)4x + 2(2 − 3x) = 6 2 要乘進括號裡每一項4x + 4 − 6x = 6，−2x = 2，x = −1 把 x = −1 代回①y = 2 − 3 × (−1) = 5
先移項成 x = …
x + 2y = 7①
3x − y = 7② ① 的 x 係數是 1，移項（要變號）x = 7 − 2y 代入②3(7 − 2y) − y = 7，21 − 7y = 7，y = 2 把 y = 2 代回①x + 4 = 7，x = 3

係數是 1 或 −1 的未知數最好移項；係數是 −1 時別忘了最後兩邊同乘 −1。

加減消去法：係數相同用減、相反用加

相反 → 加

−4x 和 4x
相加得 0

相同 → 減

12x 和 12x
相減得 0

係數相反：直接加
2x + y = 1①
4x − y = 5② y 的係數 1 和 −1 互為相反數 → ①＋② 消去 y6x = 6，x = 1 把 x = 1 代回①2 + y = 1，y = −1

課本自我檢核：這題用「①−②」消不掉 y，會得到 −2x + 2y = −4。

係數相同：相減，整條變號
3x − 9y = −3③
3x + 2y = 8② x 的係數都是 3 → ③−② 消去 x−9y − 2y = −11y、−3 − 8 = −11 −11y = −11，y = 1

減的時候 ② 的每一項都要變號。課本挑錯題小妍只變了一半，算成 −7y = 11。

係數不一樣：先乘倍數對齊

取最小公倍數
3x + 5y = 8①
4x + 3y = 7② 想消去 x：[3, 4] = 12①×4：12x + 20y = 32③
②×3：12x + 9y = 21④ ③−④ 消去 x11y = 11，y = 1 把 y = 1 代回①3x + 5 = 8，x = 1
挑好對齊的那個未知數
2x + 3y = 12①
5x + 9y = 33② y 的係數 3 和 9：只要 ①×3 就對齊6x + 9y = 36③ ③−② 消去 yx = 3

一個係數剛好是另一個的倍數，只要乘一條，少一步。

乘完要看清楚消去的是誰：3x − 4y = 13、2x + 3y = 3，①×2 和 ②×3 讓 x 的係數都變成 6，所以「①×2 − ②×3」消去的是 x，不是 y（課本自我檢核）。 想消去 y 要讓 y 的係數對齊：[4, 3] = 12，①×3、②×4，再相加。

先整理：散在兩邊、分數、小數

未知數散在等號兩邊
3x = −1 + 2x − 2y x、y 移到左邊、數字移到右邊（移過去要變號）x + 2y = −1
分數係數：乘分母的最小公倍數
x2 − y3 = 3 [2, 3] = 6，每一項都乘 63x − 2y = 18

右邊的 3 沒有分母也要乘，寫成 3x − 2y = 3 就錯了。

小數係數：乘 10
0.3x − 0.2y = 2.5 每一項都乘 103x − 2y = 25

解題順序（遊戲裡的最短走法）

  1. 有分數、小數，或未知數散在兩邊，先整理成「ax + by = c」的整數係數式子。
  2. 有現成的 x = …、y = …，或係數是 1、−1：用代入消去法，一步就消去一個未知數。
  3. 有係數相同或相反：直接相減或相加。
  4. 都沒有：挑比較好對齊的未知數，乘到兩個係數的最小公倍數，再加減。
  5. 代回任一條式子求另一個未知數（挑係數簡單的比較好算），最後代回兩條原式驗算。

常見錯誤對照表

遊戲裡的紅色按鈕大多就是左邊這一欄。
常見的錯正確為什麼
2x + y = 1、4x − y = 5，①−② 消去 y①＋② 消去 yy 的係數互為相反數要用加（課本自我檢核）
3x − 4y = 13、2x + 3y = 3，①×2 − ②×3 消去 y消去的是 x乘完 x 的係數都是 6（課本自我檢核）
x − 3y = −1、3x + 2y = 8，①×3 − ② 得 −7y = 11−11y = −11相減時 ② 的每一項都要變號（課本挑錯題小妍）
由 x = −1 + 3y 代入 3x + 2y = 8 得 y = 115−3 + 9y + 2y = 8，y = 13 要乘進括號裡每一項（課本挑錯題小美）
x − 3y = −1 → x = −1 − 3yx = 3y − 1−3y 移過等號要變號
3x 和 4x，直接相減消去 x先 ①×4、②×3係數要先對齊成最小公倍數 12
3x 和 4x，①×3、②×4①×4、②×3乘自己的係數會變成 9x 和 16x，還是對不齊
由①得 x = 3y − 1，再代回①代入另一條②代回自己只會得到 −1 = −1
x2 − y3 = 3 → 3x − 2y = 33x − 2y = 18去分母時沒有分母的項也要乘
y = 1 代入 x − 3y = −1 得 x = −4x − 3 = −1，x = 2−3 移到右邊要變號

驗算：代回兩條原式

解 3x + 5y = 8、4x + 3y = 7 得 x = 1、y = 1。代回①：3 + 5 = 8 ✓；代回②：4 + 3 = 7 ✓。
要代回兩條，而且是題目原本的式子——只代一條，可能剛好代到自己算錯的那一條。
