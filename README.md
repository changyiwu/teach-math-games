# 國中數學遊戲場

國中數學課堂小遊戲合集。純靜態網頁，不必安裝、不必登入、不必註冊帳號，打開網址就能玩。

🎮 **線上玩：<https://changyiwu.github.io/teach-math-games/>**

## 使用情境

這些遊戲是為了「**教室前方一台大螢幕**」設計的，不是為了「每個學生一台裝置」。

### 1. 課堂上：投在大螢幕，叫學生上台挑戰

- 老師用智慧白板／投影機開遊戲，抽一位學生上台，全班一起看他挑戰。
- 答對全班歡呼、答錯再換下一位，當成課堂暖身、複習或下課前的收尾活動。
- **預設班上不是每個學生都有手機或平板**，所以遊戲一律是「一台裝置、一個人操作、全班觀戰」，不需要學生各自連線、不需要掃 QR Code、不需要分組帳號。
- 所以畫面要求：字大、按鈕大、可觸控直接點，站在台上用手指就能操作完；答對答錯要有明顯的動畫與音效，讓最後一排也看得到、聽得到。

### 2. 課後：學生自己在家練

- 同一個網址直接丟給學生（或貼在班網、聯絡簿、教學網），學生用自己的手機、平板、電腦都能開。
- 不需要帳號，也不會記錄成績——定位是「自己練手感」，不是線上測驗。

> 需要全班同時用手機參與的互動（投票、文字雲、搶答），請用另外的工具，不要塞進本專案的遊戲裡。

| [🧩 面積拼圖](area-puzzle/) | 第3冊・第1章 乘法公式與多項式・第1節 乘法公式 | 用面積把乘法公式拼出來，每題兩步。第一步動手：「分配律」「和的平方」是先點色塊（如 `a²`、`ab`、`b²`）再點格子，把 (a + b)(c + d) 的長方形或 (a + b)² 的正方形拼滿，格子面積要用「長 × 寬」自己算，放錯會說明那格的長和寬；「差的平方」從 a² 剪掉左邊直條、下面橫條，左下角會顯示「剪了 2 次」，要再按「補回」才只剩黃色的 (a − b)²；「平方差」先從 a² 剪掉角落的 b²，再把乙轉 90° 接到甲的右邊，拼成長 a + b、寬 a − b 的長方形（有動畫）。第二步從四個選項選出展開式，誤答是常見錯誤：(a + b)² 寫成 a² + b²、ab 只算一塊、(a − b)² 寫成 a² − b² 或 a² − 2ab − b²、分配律只乘頭頭尾尾。難度分文字 a、b（課本推導原樣）／代數磚 x（如 (x + 3)²，數字邊畫 1 單位格線）／數字速算（如 102²、98²、203 × 197、101 × 32，圖上太細的數字段放寬並標「未依比例」）。題型分分配律／和的平方／差的平方／平方差／混合，限時依題型各自記憶（預設 45～50 秒）。題目程式生成，正解另用「邊長代數字直接相乘」驗算。附[乘法公式小抄](area-puzzle/learn.html)。 |
| [🔍 根號放大鏡](sqrt-zoom/) | 第3冊・第2章 平方根與畢氏定理・第1節 平方根與近似值 | 把課本的十分逼近法做成放大鏡。「逼近」：螢幕出 √40 這類開不盡的根號，先在整數數線上點它落在哪一格，答對後放大鏡把那一格拉滿整條數線，再點小數第 1 位（挑戰難度再點第 2 位）；每點對一層就寫出課本格式的推理「6² = 36 < 40 < 49 = 7²，所以 6 < √40 < 7」。逼近題偶爾混進 √49 這類完全平方數，要發現它剛好在刻度上、改點刻度數字。「剛好」：√144、√1.69、√(196/25)、√0.0144 等開得盡的根號，一路點到刻度上。「數線找點」：數線上 A、B、C、D 四點各在不同的一位小數格，選最接近 √19 的那一點（改寫自課本例 4）。點錯一次就結算，說明錯在哪：太左／太右（附那個刻度的平方）、剛好在刻度上卻點格子、開不盡卻點刻度。難度分基礎（100 以內，刻度下標平方值）／標準（400 以內與小數，整數那層不給平方）／挑戰（逼近到小數第 2 位，再看中點的平方四捨五入）。題型分逼近／剛好／數線找點／混合，限時依題型各自記憶（預設 40／25／25／40 秒）。所有比較都用整數精確運算，正解另用浮點數開根號驗算。附[根號小抄](sqrt-zoom/learn.html)。 |
| [✖️ 十字交乘填格](cross-factor/) | 第3冊・第3章 因式分解・第2節 利用十字交乘法做因式分解 | 螢幕出一個二次多項式（如 `x² − 5x − 14`），先點十字的格子、再點下面的數字磚，把十字的四格填好。數字磚是 x² 項係數的正因數（左欄）與常數項的正負因數（右欄）。十字下方會即時算出「左欄相乘、右欄相乘、交叉相乘的和」，對了標綠、不對標紅，就是課本「看兩端、湊中間」的試誤過程；湊對了按「送出」，怎麼拆都湊不出來就按「不能分解」（如 `x² + 4x + 8`，每級約 15% 是這種題目；缺 x 項的 `x² − 9` 當成 0x）。結果畫面寫出分解結果、畫出正解的十字並乘回原式驗算，答錯會說明錯在哪：右欄乘積的正負號不對（取自挑錯題：(−3) × (−2) ≠ −6）、乘積不是常數項、中間項差一個負號（把兩數正負對調）、右欄上下要對調、能分解卻按了不能分解。難度分 x² 係數為 1（左欄固定 x、x）／x² 係數不為 1（如 `6x² − 23x + 21`，左欄也要拆）／綜合（第一步先從四個改寫中選對，如 `−x² + 2x + 63 = −(x² − 2x − 63)`、`8y² + 40y + 50 = 2(4y² + 20y + 25)`；誤答是不提、只提 −1、括號裡沒全部變號、常數項忘了除、提出的數正負號錯。沒提乾淨的話，十字會分解成 `(2x + 2)(x − 6)` 這種還能再提公因數的結果，所以判錯；第二步才填十字）。限時依難度各自記憶（預設 30／45／60 秒）。題目程式生成，正解另用「乘回去等於原式」與判別式 b² − 4ac 是否為完全平方數驗算。附[十字交乘小抄](cross-factor/learn.html)。 |

## 課堂操作小抄

以「次方大挑戰」為例，其他遊戲的節奏也差不多：

1. 大螢幕開 <https://changyiwu.github.io/teach-math-games/>，點遊戲卡片進去。
2. 按「▶ 開始」播開場動畫（想直接上課可按「跳過 ▸」）。記得**開喇叭**。
3. 用「⏱ 限時 − ／ ＋」調秒數：第一次玩或程度較弱時放寬，熟了之後縮短加壓。設定會記在這台瀏覽器，下次打開沿用。
4. 叫學生上台，按「🎲 隨機挑題」抽題，學生直接點螢幕上的數字鍵盤作答、按「送出」。
5. 看結果動畫，按「🎲 再挑一題」換下一位。右上角有累計「答對／挑戰」次數，可以當成全班的團體成績。

1. 在專案根目錄開一個英文 kebab-case 子資料夾（例如 `factor-hunt/`），入口檔名固定為 `index.html`。
2. 在大廳 `index.html` 的 `<main class="grid">` 裡複製一張 `.card` 卡片，指向新資料夾。
3. 遊戲頁的 favicon 用 `../header-logo.svg`，「回遊戲大廳」連結用 `../index.html`。
4. 視需要在教學網 [teach-math-web](https://github.com/changyiwu/teach-math-web) 的 `tools-sidebar.js` 補上連結。

設計上請守住上面〈使用情境〉的三條底線：**一台裝置就能玩、大螢幕看得清楚、手機開也不會壞版**；外部函式庫只用固定版本的 CDN，不引入建置工具。
