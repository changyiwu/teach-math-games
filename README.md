# 國中數學遊戲場

國中數學課堂小遊戲合集。純靜態網頁，不必安裝、不必登入、不必註冊帳號，打開網址就能玩。

🎮 **線上玩：<https://changyiwu.github.io/teach-math-games/>**

## 使用情境

這些遊戲是為了「**教室前方一台大螢幕**」設計的，不是為了「每個學生一台裝置」。

### 1. 課堂上：投在大螢幕，叫學生上台挑戰

- 老師用智慧白板／投影機開遊戲，抽一位學生上台，全班一起看他挑戰。
- 答對全班歡呼、答錯再換下一位，當成課堂暖身、複習或下課前的收尾活動。
- **預設班上不是每個學生都有手機或平板**，所以遊戲一律是「一台裝置、一個人操作、全班觀戰」，不需要學生各自連線、不需要掃 QR Code、不需要分組帳號。
- 所以畫面要求：字大、按鈕大、可觸控直接點，站在台上用手指就能操作完；答對答錯要有明顯的動畫與音效，讓最後一排也看得到、聽得到。

### 2. 課後：學生自己在家練

- 同一個網址直接丟給學生（或貼在班網、聯絡簿、教學網），學生用自己的手機、平板、電腦都能開。
- 不需要帳號，也不會記錄成績——定位是「自己練手感」，不是線上測驗。

> 需要全班同時用手機參與的互動（投票、文字雲、搶答），請用另外的工具，不要塞進本專案的遊戲裡。

## 遊戲清單

| 遊戲 | 對應單元 | 玩法 |
|---|---|---|
| [⚡ 次方大挑戰](power-challenge/) | 1 上 1-4 指數記法（平方數、2 的次方） | 從 29 題次方中隨機抽一題，限時內把答案打出來就挑戰成功。限時可當場調整（預設 10 秒），附[次方表](power-challenge/learn.html)可先給學生背。 |

## 課堂操作小抄

以「次方大挑戰」為例，其他遊戲的節奏也差不多：

1. 大螢幕開 <https://changyiwu.github.io/teach-math-games/>，點遊戲卡片進去。
2. 按「▶ 開始」播開場動畫（想直接上課可按「跳過 ▸」）。記得**開喇叭**。
3. 用「⏱ 限時 − ／ ＋」調秒數：第一次玩或程度較弱時放寬，熟了之後縮短加壓。設定會記在這台瀏覽器，下次打開沿用。
4. 叫學生上台，按「🎲 隨機挑題」抽題，學生直接點螢幕上的數字鍵盤作答、按「送出」。
5. 看結果動畫，按「🎲 再挑一題」換下一位。右上角有累計「答對／挑戰」次數，可以當成全班的團體成績。

## 本機預覽

純靜態網頁，沒有建置步驟。用瀏覽器直接開 `index.html` 就能看，或起一個簡單的本機伺服器：

```bash
python -m http.server 8000
```

然後開 <http://localhost:8000>。

## 新增一款遊戲

1. 在專案根目錄開一個英文 kebab-case 子資料夾（例如 `factor-hunt/`），入口檔名固定為 `index.html`。
2. 在大廳 `index.html` 的 `<main class="grid">` 裡複製一張 `.card` 卡片，指向新資料夾。
3. 遊戲頁的 favicon 用 `../header-logo.svg`，「回遊戲大廳」連結用 `../index.html`。
4. 視需要在教學網 [teach-math-web](https://github.com/changyiwu/teach-math-web) 的 `tools-sidebar.js` 補上連結。

設計上請守住上面〈使用情境〉的三條底線：**一台裝置就能玩、大螢幕看得清楚、手機開也不會壞版**；外部函式庫只用固定版本的 CDN，不引入建置工具。
