坐標小抄

康軒 1 下 2-1 直角坐標平面。坐標 ( m , n )：m 是 x 坐標（左右），n 是 y 坐標（上下）。

怎麼找到一個點

  1. 從原點 O ( 0 , 0 ) 出發。
  2. 看 x 坐標：正的往右、負的往左，走幾格。
  3. 再看 y 坐標：正的往上、負的往下，走幾格。
  4. 反過來讀點：從點畫鉛垂線到 x 軸讀 x 坐標，畫水平線到 y 軸讀 y 坐標。
( m , n ) 和 ( n , m ) 不一樣（m ≠ n 時）：圖中的 A ( 5 , 2 ) 是「右 5、上 2」，( 2 , 5 ) 卻是「右 2、上 5」，兩個點不同。
½ 的坐標：例如 212（也寫成 2.5）要點在 2 和 3 兩條格線的正中間。

四個象限的符號：第一象限 ( ＋ , ＋ )、第二象限 ( − , ＋ )、第三象限 ( − , − )、第四象限 ( ＋ , − )；坐標軸上的點不屬於任何象限。
例：P 在第三象限，到 x 軸距離 2、到 y 軸距離 6 → |y| = 2、|x| = 6，符號 ( − , − )，所以 P ( −6 , −2 )。

點的平移

往哪裡走，就改哪個坐標
移動改的坐標
向右 k 單位x 坐標 ＋ k，y 不變
向左 k 單位x 坐標 − k，y 不變
向上 k 單位y 坐標 ＋ k，x 不變
向下 k 單位y 坐標 − k，x 不變
正推：從 C ( −4 , −1 ) 先向右 6、再向上 4 → x：−4 + 6 = 2，y：−1 + 4 = 3 → D ( 2 , 3 )。
倒推：E 點先向下 5、再向左 3，到達 F ( −1 , −2 )。從 F 反方向走回去：向右 3、向上 5 → x：−1 + 3 = 2，y：−2 + 5 = 3 → E ( 2 , 3 )。也可以設 E ( a , b )，列 a − 3 = −1、b − 5 = −2 來解。

常見的錯正確
( 3 , −2 ) 點在「右 2、下 3」 先 x 後 y：右 3、下 2（x、y 不能對調）
( 0 , 4 ) 點在 x 軸上 x 坐標是 0 → 在 y 軸上，原點上方 4
( −3 , 2 ) 點在原點右邊 x 是負的 → 往左走 3
數格子時把原點 O 也算成一格 從 O 出發，走過一條格線才算 1 格
112 點在格線 1 上 點在 1 和 2 的正中間
到 x 軸的距離看 |x| 到 x 軸是上下量，看 |y|
向左 4 單位：x 坐標 ＋ 4 向左是 x 坐標 − 4；向右才是 ＋
向上 3 單位：x 坐標 ＋ 3 上下移動改的是 y 坐標
