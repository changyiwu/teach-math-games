根號小抄

康軒 2 上 2-1 平方根與近似值。面積是 a 的正方形，邊長就是 √a，所以 (√a)² = a。比根號的大小，就是比平方的大小。

三個重點

若 a > b > 0，則 √a > √b

面積大的正方形，邊長也比較大。例如 √46 < √49 < √50，而 √49 = 7。

完全平方數：√a² = a（a > 0）

√169 = √13² = 13；數字大就先質因數分解：√784 = √2⁴ × 7² = 2² × 7 = 28。

小數、分數也一樣：√1.69 = 1.3，√9/25 = 3/5 = 0.6。

開不盡的：用平方「夾住」它

6² = 36 < 40 < 49 = 7²，所以 6 < √40 < 7。夾住之後，再把 6～7 分成 10 等分繼續夾，這就是十分逼近法。

十分逼近法：放大鏡三步

  1. 找整數：5² = 25 < 34 < 36 = 6²，所以 5 < √34 < 6。
  2. 5～6 分成 10 等分：5.8² = 33.64 < 34 < 34.81 = 5.9²，所以 5.8 < √34 < 5.9。
  3. 5.8～5.9 再分 10 等分：5.83² = 33.9889 < 34 < 34.1056 = 5.84²，所以 5.83 < √34 < 5.84。

四捨五入：看中點

已知 5.83 < √34 < 5.84，要四捨五入到小數點後第 2 位，只要看第 3 位是不是 ≥ 5，也就是和中點 5.835 比：
5.835² = 34.047225 > 34，所以 √34 < 5.835，第 3 位小於 5 → √34 ≒ 5.83。

數線找點

哪一點最接近 √19？先夾整數：4² = 16 < 19 < 25 = 5²；再夾一位小數：4.3² = 18.49 < 19 < 19.36 = 4.4²。
所以 √19 在 4.3 和 4.4 之間，落在這一格的點就是答案。
