指數律小抄

康軒 1 上 2-4。下面 a、b 都是不為 0 的數，m、n 是正整數或 0。

四條指數律

1
am × an = am+n

同底數相乘 → 指數相加。

52 × 54 = 56
2
am ÷ an = am−n

同底數相除 → 指數相減（課本限 m ＞ n）。

(−2)5 ÷ (−2)2 = (−2)3
3
( am )n = am×n

乘方的乘方 → 指數相乘。

( 54 )2 = 58
4
( a × b )m = am × bm

兩數相乘的乘方 → 每個底數各自次方。

( 7 × 11 )4 = 74 × 114
零次方：只要 a 不是 0，就規定 a0 = 1。例如 100 = 1、(−3)0 = 1、(−1998)0 = 1。
這是為了讓 am ÷ an = am−n 在 m = n 時也成立：73 ÷ 73 = 1，也等於 70。

負數、分數的乘方

(−a)n

負號在括號裡，連負號一起乘 n 次。
n 是偶數 → (−a)n = an；
n 是奇數 → (−a)n = −an。

(−2)6 = 26、(−2)5 = −25
−an

負號不在括號裡，只有 a 自乘 n 次，算完才加負號，所以永遠是負的。

−26 ≠ (−2)6；−25 = (−2)5
(ba)n = bnan

分數的乘方 → 分子分母都要次方。

(35)2 = 3252
比較大小

底數 0 ~ 1 之間：指數愈大，值愈小。
底數大於 1：指數愈大，值愈大。

(23)3 ＜ (23)2 ＜ 1

常見錯誤對照表

遊戲裡的「錯誤」選項大多長得像左邊這一欄。
常見的錯正確
a3 × a4 = a12 a3 × a4 = a7（指數相加）
a8 ÷ a2 = a4 a8 ÷ a2 = a6（指數相減）
( a3 )4 = a7 ( a3 )4 = a12（指數相乘）
( a × b )5 = a5 × b ( a × b )5 = a5 × b5
a5 + a5 = a10 a5 + a5 = 2a5（相加不是相乘）
( 2 + 3 )2 = 22 + 32 = 13 ( 2 + 3 )2 = 52 = 25（加法不能拆）
a0 = 0 a0 = 1（a 不為 0）
(−3)4 = −34 指數是偶數 → (−3)4 = 34；指數是奇數才 (−3)5 = −35
(23)2 = 232（只有分母次方） (23)2 = 2232
23 × 32 = 65 指數一樣才能併底數：23 × 33 = 63
