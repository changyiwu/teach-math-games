函數小抄

康軒 2 下 2-1 函數與函數圖形。判斷只有一句話：給定每一個 x，都恰好有一個 y 和它對應，y 就是 x 的函數。一個 x 對到兩個以上的 y 就不是；不同的 x 對到同一個 y 沒關係。

四種題目怎麼看

① 對應表、箭頭圖

找有沒有同一個 x 出現兩次、卻對到不同的 y；箭頭圖就看有沒有一個 x 射出兩支箭頭。

x1231
y4557
x = 1 對到 4 和 7 → 不是函數
x = 2、3 都對到 5 → 這一點沒關係
② 圖形：鉛垂線檢驗

想像一條鉛垂線（直的線）由左往右掃過去，只要有一個位置碰到圖形兩點以上，就不是函數。

左：每條鉛垂線只碰一點 → 是函數
右：圓會碰到兩點 → 不是函數
③ 式子

試著整理成「y = ……」。代一個 x 進去只算出一個 y 才是函數。

y = 2x + 1、x = 3y − 6、y = x2 → 是函數
y2 = x：x = 4 時 y = 2 或 −2 → 不是
x2 + y2 = 25、|y| = x、x = 3 → 不是
④ 生活情境

挑一個 x 的值試試看：能不能找到兩個不同的 y？找得到就不是函數。

正數 x 的平方根 y：4 的平方根有 2 和 −2 → 不是
周長 x 的長方形面積 y：周長 12 可以是 3×3 或 4×2 → 不是
正方形邊長 x、面積 y：y = x2 → 是函數

挑戰難度：一次函數、常數函數、不是函數

一次函數 y = ax + b（a ≠ 0）

圖形是斜直線。式子要先整理：x 的係數不是 0 就是一次函數，b = 0 也可以。

2x + y = 5 → y = −2x + 5
x = 2y + 4 → y = 12x − 2
常數函數 y = b

不論 x 是多少，y 都一樣。圖形是水平線（平行 x 軸）。

3y − 6 = 0 → y = 2
y + 2x = 2x + 5 → y = 5（x 消掉了）
停車不論停多久都收 50 元 → y = 50
鉛垂線 x = c：不是函數

圖形平行 y 軸。x = c 時 y 可以是任何數，不是常數函數，根本不是函數。

x = 3、2x − 6 = 0 → 不是函數
y2 = 9：y 可以是 3 或 −3 → 也不是函數
一次函數、常數函數合稱線型函數，圖形都是直線。但「是直線」不代表一定是函數：鉛垂線就不是。

常見迷思對照表

遊戲裡容易答錯的題目大多是左邊這種想法。
常見的想法正確
兩個不同的 x 對到同一個 y，所以不是函數 多個 x 對到同一個 y 可以；不行的是一個 x 對到多個 y
每個 x 都對到同一個 y，太奇怪了，不是函數 每個 x 還是恰有一個 y，是函數（常數函數）
表格裡 x = 2 出現兩次，所以不是函數 要看兩次對到的 y 一不一樣；一樣的話還是只有一個 y
x = 3 和 y = 3 一樣，都是常數函數 y = 3 是水平線，是常數函數；x = 3 是鉛垂線，不是函數
直線都是函數 斜直線、水平線是；鉛垂線不是
x = 2y + 4 是「x = ……」，所以不是 y 對 x 的函數 先整理成 y = 12x − 2，每個 x 只有一個 y，是一次函數
曲線一定不是函數 拋物線 y = x2、V 字形 y = |x| 都通過鉛垂線檢驗，是函數；圓、開口朝左右的曲線才不是
