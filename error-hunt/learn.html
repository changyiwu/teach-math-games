解一元二次方程式小抄

康軒 2 上第 4 章。方程式經化簡後可寫成 ax² + bx + c = 0（a ≠ 0），就是一元二次方程式；把某數代入後等號兩邊相等，這個數就是它的解（根）。抓錯行的關鍵：每一行都要和上一行有一樣的解。

四種解法與使用時機

因式分解（4-1）

先移項讓一邊是 0，再分解成兩個一次式相乘。若 A × B = 0，則 A = 0 或 B = 0。

x² + 5x = 6
x² + 5x − 6 = 0
(x + 6)(x − 1) = 0
x = −6 或 x = 1
適合：提公因式、乘法公式、十字交乘分得開的題目
平方根（4-2）

整理成 (x + h)² = k，k > 0 時開平方要寫 ±。

(x + 1)² = 2
x + 1 = ±√2
x = −1 ± √2
適合：已經是「某式的平方 = 數」的題目
配方法（4-2）

x² 係數先變成 1（每一項都除），常數移到右邊，兩邊同加 (b2)²。

x² − 4x − 396 = 0
x² − 4x + 2² = 396 + 2²
(x − 2)² = 400
x = 22 或 x = −18
適合：常數項很大、十字交乘不好試的題目
公式解（4-2）

先化成一般式找 a、b、c，算判別式 b² − 4ac，≥ 0 才代公式。

x = −b ± √b² − 4ac2a
分子是 −b；分母 2a 要除整個分子

判別式 b² − 4ac

判別式解的情形例子
> 0兩個相異的根2x² − 9x + 5 = 0：81 − 40 = 41 > 0
= 0兩根相等（重根），x = −b2a4x² + 4x + 1 = 0：16 − 16 = 0
< 0無解（負數沒有平方根）x² + x + 2 = 0：1 − 8 = −7 < 0
注意：c 是負數時，−4ac 會變成加：3x² + 7x − 2 = 0 的判別式是 49 − 4 × 3 × (−2) = 49 + 24 = 73。

應用問題四步驟

  1. 設未知數：設小翊的年齡為 x 歲。
  2. 列方程式：「單價的 2 倍少 20」是 2x − 20，不是 2(x − 20)；沿四邊開路，長、寬都扣 2x，十字形道路只扣 x。
  3. 解方程式：因式分解、配方法或公式解。
  4. 檢查並寫答案：年齡、價格、長度不能是負的，路不能比草地寬；題目問的是 x 還是 x + 4，要回頭讀題目。
