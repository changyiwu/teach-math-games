移項法則小抄

康軒 1 上 3-2。解方程式就是一步一步把它變成 x = □：x 項留左邊、數字全搬右邊、最後把 x 前面的係數除掉。

等量公理：兩邊做一樣的事

等號就像一座平衡的天平。等號兩邊同加、同減、同乘、同除以同一個數，等號仍然成立—— 但除數不能是 0。
1
同減 3
5x + 3 = 18兩邊同減 35x + 3 − 3 = 18 − 3整理5x = 15
2
同除以 5
5x = 15兩邊同除以 55x ÷ 5 = 15 ÷ 5整理x = 3
3
同乘 3
x3 = 4兩邊同乘 3x3 × 3 = 4 × 3整理x = 12

移項法則：搬過等號就變號

等量公理寫久了會發現：其實就是把某一項搬到等號另一邊，再換成相反的運算。

加 → 減

x + 7 = 10
x = 10 − 7

減 → 加

x − 4 = 9
x = 9 + 4

乘 → 除

6x = 3
x = 3 ÷ 6 = 12

除 → 乘

x5 = −2
x = −2 × 5

乘變除，要除的是「x 前面的係數」：6x = 3 是「6 乘 x 等於 3」，所以 x = 3 ÷ 6，不是 6 ÷ 3。 先想清楚「誰被誰除」，再動筆。

解題順序（遊戲裡的最短走法）

  1. 有分母先去分母：兩邊乘所有分母的最小公倍數，而且每一項都要乘，包括沒有分母的那一項。
  2. 有括號就處理括號：用分配律去括號；如果另一邊剛好是括號外係數的倍數，也可以直接兩邊同除，少一步。
  3. x 項搬左邊、數字搬右邊：搬過等號要變號，再合併同類項。
  4. 除以 x 的係數：得到 x = □。
  5. 驗算：把答案代回原來的方程式，左右兩邊算出來相等才對。

去分母：每一項都要乘

✓ 正確
x + 32 = x − 13 + 2兩邊同乘 6（2 和 3 的最小公倍數）3(x + 3) = 2(x − 1) + 12去括號、合併3x + 9 = 2x + 10移項x = 1
✗ 課本挑錯題：小翊的錯
x + 32 = x − 13 + 2只把分數乘 63(x + 3) = 2(x − 1) + 2去括號、合併3x + 9 = 2x移項x = −9 ✗

右邊的 +2 沒有分母也要乘 6。驗算 x = −9：左邊 −3、右邊 −4／3，不相等，就知道錯了。

驗算：代回原式

解 5x + 3 = 18 得 x = 3。代回原式：左邊 5 × 3 + 3 = 18，右邊 = 18，兩邊相等，所以 x = 3 是這個方程式的解。
驗算要代回題目原本的式子，不要代回自己算到一半的那一行（那一行如果已經錯了，代進去也會「相等」）。

常見錯誤對照表

遊戲裡的紅色按鈕大多就是左邊這一欄。
常見的錯正確為什麼
5x + 3 = 18 → 5x = 18 + 35x = 18 − 3+3 搬過去要變號（加變減）
x − 4 = 9 → 兩邊同減 4兩邊同加 4要消掉 −4，得做相反的運算 +4
6x = 3 → x = 6 ÷ 3x = 3 ÷ 6 = 12要除以 x 的係數 6，除的方向別反了
5x = 35 → 兩邊同乘 5兩邊同除以 55x 是 5 乘 x，乘變除
5x = 35 → 兩邊同減 5兩邊同除以 55x 不是 5 ＋ x，加減消不掉乘法
x3 = 4 → 兩邊同除以 3兩邊同乘 3x 被除以 3，除變乘
x + 3 = 10 → 兩邊同除以 3兩邊同減 3+3 是加上去的，不是乘上去的
2(x − 3) = 8 → 兩邊同加 3兩邊同除以 2−3 包在括號裡，外面還乘著 2
8x + 13 = 6x + 3 → 兩邊同加 6x兩邊同減 6x要消掉 +6x 得減 6x
去分母時沒有分母的項不乘每一項都乘最小公倍數課本挑錯題小翊的錯
分母 2 和 3，兩邊同乘 5兩邊同乘 6要乘最小公倍數，不是分母相加
若 a × c = b × c，則 a = b不一定c 可能是 0：3 × 0 = 5 × 0，但 3 ≠ 5。所以除數不能是 0
