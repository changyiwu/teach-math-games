乘法公式小抄

康軒 2 上 1-1 乘法公式。長方形的面積是長 × 寬，把一塊大圖切成幾小塊，大圖面積 = 小塊面積加起來，四個公式都是這樣來的。

四個公式，四張圖

分配律
(a + b)(c + d) = ac + ad + bc + bd

大長方形切成甲、乙、丙、丁四塊，每一塊都是「一段長 × 一段寬」，四塊都要算到。

和的平方公式
(a + b)² = a² + 2ab + b²

大正方形 = 1 塊 a² + 2 塊 ab + 1 塊 b²。中間那兩條長方形別忘了。

差的平方公式
(a − b)² = a² − 2ab + b²

從 a² 剪掉兩條 ab，左下角的 b² 被剪了兩次，所以要補回一次。

平方差公式
(a + b)(a − b) = a² − b²

a² 剪掉角落的 b² 剩下 L 型；把乙轉過來接在甲的右邊，拼成長 a + b、寬 a − b 的長方形，面積不變。

用分配律也推得出來：(a + b)² = (a + b)(a + b) = a² + ab + ba + b² = a² + 2ab + b²。
公式裡的 a、b 可以換成任何數或文字，例如 (x + 3)² = x² + 2 × 3x + 3² = x² + 6x + 9。

數字速算：拆成整十、整百

102² = (100 + 2)²
= 100² + 2 × 100 × 2 + 2²
= 10000 + 400 + 4 = 10404
98² = (100 − 2)²
= 100² − 2 × 100 × 2 + 2²
= 10000 − 400 + 4 = 9604
203 × 197 = (200 + 3)(200 − 3)
= 200² − 3²
= 40000 − 9 = 39991
101 × 32 = (100 + 1)(30 + 2)
= 3000 + 200 + 30 + 2
= 3232

公式反過來用

61² + 2 × 61 × 39 + 39² = (61 + 39)² = 100² = 10000
655² − 345² = (655 + 345)(655 − 345) = 1000 × 310 = 310000

常見錯誤對照表

遊戲的錯誤選項大多是左邊這幾種，代一組數字進去就看得出來。
常見的寫法正確
(a + b)² = a² + b² 少了中間兩塊：a² + 2ab + b²。試 (5 + 1)² = 36，5² + 1² = 26
(a + b)² = a² + ab + b² 長方形 ab 有兩塊
(a − b)² = a² − b² a² − 2ab + b²。試 (7 − 2)² = 25，7² − 2² = 45
(a − b)² = a² − 2ab − b² 角落剪了兩次，要補回：+ b²
(a + b)(c + d) = ac + bd 四塊都要算：ac + ad + bc + bd
長 x、寬 3 的長方形面積是 x + 3 面積是長 × 寬 = 3x；x + 3 是兩邊加起來
